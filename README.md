## 📌 Project Overview

This project analyzes marketing funnel performance to understand how visitors move through different stages of the customer journey. Using Python and data analytics techniques, the project calculates conversion rates, identifies drop-off points, and visualizes funnel performance to help businesses improve marketing effectiveness.

Developed as part of the **Future Interns Data Analytics Internship Program**.

---

## 🎯 Objectives

* Analyze visitor-to-customer conversion performance.
* Measure lead generation effectiveness.
* Calculate conversion percentages at each funnel stage.
* Identify major customer drop-off points.
* Visualize marketing funnel performance using charts.
* Generate business insights for marketing optimization.

## 📈 Analysis Performed

### 1️⃣ Data Loading & Exploration

* Imported dataset using Pandas.
* Displayed dataset preview.
* Checked data structure and values.

### 2️⃣ Conversion Rate Calculation

Calculated:

* Lead Conversion Rate (%)
* Customer Conversion Rate (%)

Formula:

```python
Lead Conversion % = (Leads / Visitors) × 100
Customer Conversion % = (Customers / Visitors) × 100
```

### 3️⃣ Funnel Drop-Off Analysis

Measured customer loss between stages:

* Visitor → Lead
* Lead → Qualified Lead
* Qualified Lead → Customer

### 4️⃣ Data Visualization

Created visual charts to represent:

* Conversion performance
* Funnel effectiveness
* Customer drop-off analysis
